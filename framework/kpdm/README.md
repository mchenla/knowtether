# KPDM：知识产品开发元模型

KPDM 帮助人从问题、经验与材料出发，形成别人能理解、能使用、能检查的知识成果。它支持文章、研究报告、书籍、框架与系列成果；人决定目标、主张、取舍、接受与发布，Agent 在授权内研究、起草、质疑和核对。

这里提供作者规范的公开快照。**KPDM 是方法规范，KnowTether 是所选要求的 Agent 实现**。不安装插件也可以使用规范和模板；安装插件不表示满足完整 KPDM。

## 从一个任务开始

1. 阅读[快速入门](spec/00%20Start/快速入门.md)。
2. 在自己的创作项目使用[轻量工作单](spec/04%20Templates/轻量工作单模板.md)，先写到够用；不要在插件缓存中创作。
3. 需要时查阅[创作内核](spec/01%20Foundations/KPDM%20三层元模型.md)、[质量约束](spec/01%20Foundations/KPDM%20质量约束.md)和[人机协作协议](spec/02%20Methods%20and%20Protocols/人机协作协议.md)。
4. 按读者任务检查成果，分别记录起草、作者接受、独立核验与发布决定。

完整导航见[知识索引](spec/KPDM%20知识索引.md)。[机器模型与 Schema](spec/05%20Machine%20Model/)提供可选的结构支持，不替代事实核验或真实读者检查。
