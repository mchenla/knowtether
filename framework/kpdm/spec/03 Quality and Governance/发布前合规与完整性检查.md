# 发布前合规与完整性检查

0.5.0-rc.2 未改变清单条目，只增加「轻量入口的最少检查」一节并更新版本身份。清单条目本身保持 0.4.4 内容。

## 轻量入口的最少检查

用一张工作单完成的文章或报告，对外发布前至少核对下列项目，并把结果写进工作单「结果与修订」和「人的决定」：

- [ ] 意图中的用途为公开，且 Q 目标至少 Q3；
- [ ] 中心思想对应的核心主张已分类，依据可定位，未知项显式保留；
- [ ] 依据与适用范围中的每项外部材料有 rights_status，无 blocked-unknown-rights；
- [ ] 委托范围中 Agent 起草的事实、引文和数据已经人工核验；
- [ ] 验收条件中的读者任务由真实目标读者或独立编辑执行，结果已记录；
- [ ] 人的决定记录了接受的具体版本，发布决定与接受决定分开；
- [ ] 下列 Release Gate 中权利、真实性、隐私与成品表达隔离各节逐项通过。

轻量入口只减少记录形式，不减少上述检查。

## Release Gate

### 身份与质量

- [ ] Profile 和 Q 级明确；
- [ ] 标题、摘要、封面和营销承诺不超过正文证据；
- [ ] 作者、贡献者、资助和利益冲突已披露；
- [ ] AI 使用已按 Q 级记录。

### 主张与证据

- [ ] 所有核心事实和外部数据可追溯；
- [ ] 引文逐字核实并有稳定定位；
- [ ] 解释、因果、预测和规范选择没有冒充事实；
- [ ] 反例、边界和重大未知已披露；
- [ ] 高风险结论有独立复核；
- [ ] 每条引用经核对确实支持所引主张；资料之间的推测关系没有被写成已核实事实；只取得搜索摘要的材料标为未核对原文。
### 状态与公开宣称

- [ ] “完成、完整、写透、成熟、有效、可靠、可用、拿来即用、经过验证、标准、权威、中立、领先、国际化、世界级”等状态词均有对象、范围、判据、证据、验证者、版本和限制；
- [ ] 生产状态、质量状态和发布状态没有混写；
- [ ] 作者自检、AI 自评、结构检查、虚拟案例和自举测试没有被改写为独立验证或真实效度；
- [ ] 派生视图没有提高权威源状态，也没有删除必要限制；
- [ ] Q3–Q4 高影响状态主张已有独立复核，或明确标为 provisional、self-assessed 或 unverified；
- [ ] 研究任务中，人要求停止或缩小范围后没有继续扩展；预算耗尽没有被写成知识问题已经解决。

### 权利

- [ ] 每项外部材料有 rights_status；
- [ ] 图片、图表、截图、代码和长引文许可清晰；
- [ ] CC 许可证版本及 BY/NC/ND/SA 条件满足；
- [ ] 翻译、改编和重绘有权利基础及修改说明；
- [ ] blocked-unknown-rights 数量为零。

### 数据

- [ ] 数据集作者、名称、版本、仓库、ID、访问日期和许可完整；
- [ ] 关键数字区分原始、作者计算和估算；
- [ ] 清洗、筛选、单位、币种、通胀和时间范围可复算；
- [ ] 图表脚注包含来源和变换；
- [ ] 不确定性、缺失和不可比性已说明。

### 隐私与保密

- [ ] 个人信息有合法和必要的处理依据；
- [ ] 客户、内部或保密材料已获发布授权；
- [ ] 案例匿名化不能被轻易反识别；
- [ ] AI 工具中未暴露未授权敏感信息。

### 编辑与可用性

- [ ] 术语、编号、交叉引用和参考文献一致；
- [ ] 链接和 DOI 可用；
- [ ] 目标读者测试完成；
- [ ] 无障碍、图表说明和媒介格式达标；
- [ ] **中文输出物（PPT/Word/PDF 等）无红色下划线**：既不用红色装饰性下划线/横线压在中文文本下方；也已消除办公软件把中文当外语拼写检查产生的红色波浪线（生成 Office 文档时对中文 run 设 `noProof`/正确 `lang`）；
- [ ] **色块/矩形内文字与填充色对比充分**：深色填充配浅（白）色字、浅色填充配深色字；不得深字压深底或浅字压浅底（低对比、不可读，含正文/描述文字而非仅标题）；同一组并列色块统一同一套「底色—字色」方案（如统一浅底深字），不让个别深底块混入浅底组造成对比失衡；交付前对每个有填充的形状逐一核对文字可读性；
- [ ] 发布版本、日期、限制和反馈入口明确。


### 模型语言与文字温度


- [ ] 已检查大模型偏好词、高频抽象词、机械排比、口号式对仗和固定句式；
- [ ] 明显的机器输出表面形式已去 AI 化：长破折号（—，em dash）一律替换为空格短横线空格 " - "；其它 AI 惯用排版（成对花式引号、连排 em-dash 插入语、统一花样项目符号等）改按人类自然写法处理；
- [ ] “锁、情境、边界、证据、循证、纪律、铁律”等词均按具体含义使用，不作为万能表达支架；
- [ ] 可以直接说明的人、事、责任、资料和行动未被不必要地改写为模型语言；
- [ ] 自造概念、缩写、层级和成组术语均已通过新术语准入检查；
- [ ] 正文能够自然朗读，并由目标读者或独立编辑检查文字温度、专业性和人类自然表达；

### 成品表达隔离

- [ ] 封面、标题、页眉、正文、演示页和工具界面不含“候选发布版”“内部探讨参考”“供某人审阅”等工作流标签；
- [ ] 思考过程、生成过程、任务完成说明、会话信息、资料库路径和未授权框架名称已从成品移除；
- [ ] “本文件不宣称”“作者认为”“不得自证”等自我说明已改写为对象、证据、验证者、生效条件或适用边界的直接规则；
- [ ] 面向编辑者的检查清单、修改理由和发布前提示未混入读者正文；
- [ ] 保留的版本、状态、限制或披露对读者使用、法律合规或监管要求具有明确必要性；
- [ ] 对最终可见文本执行元话语扫描，命中项均有读者价值说明或已删除。

任一权利、真实性、隐私或成品表达隔离红线失败，Release Gate 直接 fail。
