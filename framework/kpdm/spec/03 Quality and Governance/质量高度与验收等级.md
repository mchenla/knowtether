# 质量高度、验收与校验

本文件回答三个问题：成果要达到什么高度（Q0–Q4 与十维模型），高度怎样变成可检查的门槛（QualitySLO、置信向量、不确定性），检查怎样进行并形成结论（读者任务验证、验证合同与 PDCA）。自 0.5.0-rc.2 起，原《质量SLO、置信向量与不确定性治理》与《PDCA 成果校验与进度治理》并入本文件。六项质量约束本身见 [KPDM 质量约束](../01%20Foundations/KPDM%20%E8%B4%A8%E9%87%8F%E7%BA%A6%E6%9D%9F.md)；发布前逐项清单见 [发布前合规与完整性检查](%E5%8F%91%E5%B8%83%E5%89%8D%E5%90%88%E8%A7%84%E4%B8%8E%E5%AE%8C%E6%95%B4%E6%80%A7%E6%A3%80%E6%9F%A5.md)。

## 五级质量目标

| 等级 | 定位 | 允许用途 | 最低验收 |
|---|---|---|---|
| Q0 Capture | 原始捕捉 | 私人灵感、摘录、临时记录 | 来源尽量保留；不得对外发布 |
| Q1 Working | 工作草案 | 内部思考、讨论、探索 | 主张与未知分开，显著标草案 |
| Q2 Professional | 专业内部版 | 内部决策、客户工作底稿、课程试讲 | 关键事实核验、结构一致、权利初审、责任人签字 |
| Q3 Publishable | 可出版版 | 文章、报告、公开课程、一般出版物 | 完整来源、权利清晰、独立事实与编辑检查、读者测试 |
| Q4 Authority Candidate | 权威候选版 | 知识体系、旗舰著作、长期标准或世界级候选 | Q3 全部要求，加原创贡献比较、外部同行评审、现实验证、版本治理和公开限制 |

Q4 是“权威候选”，不是自授权威。世界级是外部采用、同行评价、跨地区案例和时间共同形成的结果。

每个实例必须用下文的 QualitySLO 将 Q 级转换为可测试的门槛。Q 级是目标高度，不等于实际达到；实际状态由 SLO、置信向量、回归和外部验证共同决定。

## 十维质量模型

| 维度 | 核心问题 |
|---|---|
| Truth | 事实和数字是否准确 |
| Contribution | 新贡献是否清楚且没有夸大 |
| Architecture | 对象、关系、层级和论证是否一致 |
| Evidence | 证据是否与主张匹配且充分 |
| Rights | 引用、许可、隐私和保密是否合规 |
| Usefulness | 是否解决目标读者的真实任务 |
| Reproducibility | 方法、计算或判断能否复现 |
| Readability | 是否清晰、连贯、适配媒介 |
| Editorial | 语言、图表、引用、格式和索引是否专业 |
| Governance | 版本、责任、反馈和修正是否可追踪 |

## 等级门槛

- Q2：十维均不得低于“可接受”，Truth、Rights 不得有未关闭高风险项；
- Q3：十维均通过，Truth、Evidence、Rights、Readability、Editorial 必须有独立 Check；
- Q4：除 Q3 外，Contribution、Usefulness、Reproducibility 必须有外部或现实验证。

不使用平均分掩盖红线。Truth 或 Rights 失败时，总体直接 fail。

## 默认设定

- 私人笔记：Q0；
- 内部工作稿：Q1；
- 专业内部成果：Q2；
- 任何公开文章或出版物：至少 Q3；
- 新知识体系、旗舰著作、标准化方法：Q4 candidate。

## 读者任务验证

实质生产前，每件成果至少声明一项读者任务：目标读者读完后应能理解、判断、学习、行动或创造什么。任务写进工作单「验收条件」或 QualitySLO 的 Usefulness 维度，并预先给出通过判据与评分规则。

检查时记录：

1. 谁执行了任务：真实目标读者、独立编辑，还是作者自检；AI 模拟的读者反馈只能作为起草阶段的线索，不得填入真实读者结果；
2. 任务是否完成，未完成的原因：关键意义被误解、适用条件被误解、步骤无法执行、术语不能复述；
3. 处置：修订相关内容后复测，或限制用途并记录原因。

关键意义或适用条件被误解时必须修订并复测，不能用平均满意度抵消。Q0–Q2 把结果记为改进项；Q3–Q4 公开成果按 [KPDM 质量约束](../01%20Foundations/KPDM%20%E8%B4%A8%E9%87%8F%E7%BA%A6%E6%9D%9F.md) 作为硬门处理。

成果读者与框架使用者分别验证：作者能使用 KPDM，不代表其作品已对读者有用；作品被读者理解，也不自动证明 KPDM 降低了创作成本。作者理解、研究过程、最终稿与读者任务四者分开评价；不以引用数量、Agent 数量或语言模型评分代替这些结果。

## QualitySLO、置信向量与不确定性

### QualitySLO

QualityTarget 规定产品最终高度；QualitySLO 把高度转换为某个 WorkPacket 或 ReleaseCandidate 的可测试门槛。每个 SLO 包含维度、指标、阈值、检查方法、证据、责任人和红线。

示例：核心事实可追溯率 100%；高风险数据二次核验率 100%；术语冲突 0；关键任务读者测试成功率达到预设阈值。阈值必须在 Do 前冻结。

不以平均分掩盖红线。Truth、Rights 或安全红线失败时，ReleaseCandidate 直接失败。

### 置信向量

复杂知识产品不得只给一个貌似精确的总分。使用七维置信向量记录判断基础：

| 代码 | 维度 | 核心问题 |
|---|---|---|
| C | Claim | 主张是否清晰、有限定且无冲突 |
| E | Evidence | 证据是否直接、充分、时效适当 |
| A | Architecture | 对象、依赖和定义是否一致 |
| R | Rights | 权利、隐私与许可是否可发布 |
| U | Usefulness | 目标受众能否完成预期任务 |
| P | Process | 过程、版本和裁决是否可追踪 |
| X | External | 是否获得独立或现实验证 |

每维只使用 `low / medium / high / not-tested`，并链接依据。向量表达的是证据状态，不是事实概率。任一关键维 `not-tested` 时，不得声称总体高置信。

### UncertaintyItem

所有可能影响主张、架构、权利、数据、使用或发布的未知项必须对象化，字段包括：问题、类型、影响、概率区间、风险等级、负责人、解决方法、截止点、状态和处置。

状态：`open → investigating → resolved / accepted / invalidated`。

accepted 不是已解决，必须说明接受理由、残余风险和允许用途。高风险未知不得 accepted 后直接进入 Q3/Q4 发布。

### 不确定性燃尽

按风险加权，不按数量美化：高风险=8，中风险=3，低风险=1。

`Uncertainty Load = Σ(开放项 × 风险权重)`

每轮记录起始负荷、关闭负荷、新增负荷和期末负荷。新增合理未知可能使曲线上升，这通常说明 Check 有效，不应被视为进度倒退。

### 预测指标

- 周期区间：同 profile、同复杂度历史包的 P50–P80；
- 返工率：发生至少一次返工的关闭包比例；
- 缺陷逃逸率：发布后发现缺陷 / 发布前后全部缺陷；
- SLO 达成率：通过指标 / 应检查指标，红线另计；
- 不确定性清除率：本轮关闭负荷 /（期初负荷 + 新增负荷）。

没有足够历史样本时，明确标注“不可校准”，不得制造确定日期或成功概率。

## 验证合同与 PDCA 校验

### 验证合同

每轮 Plan 必须先冻结目标、范围、输入基线、产物、验收门槛、检查方式、独立视角及失败条件。Do 后修改门槛等同于取消该轮验证。

Plan 应生成或引用工作单或 ContextPack、WorkPacket、QualitySLO 和起始 Uncertainty Load。Check 应执行适用 RegressionTest；Act 应形成发布、限用、返工或废止裁决。

### 六维 Check

| 维度 | 问题 |
|---|---|
| 完整性 | 约定产物是否齐全 |
| 一致性 | 与权威定义、其他视图和版本是否一致 |
| 正确性 | 事实、逻辑、公式、引用和关系是否成立 |
| 可复现性 | 另一主体能否用相同输入得到可接受的一致结果 |
| 可用性 | 目标用户能否理解并完成预期任务 |
| 边界与风险 | 未知、反例、失败模式和适用限制是否披露 |

### Check 结论

- pass：达到冻结门槛；
- conditional-pass：仅在明确限制内可用；
- fail：返回 Do，不得包装为通过。

### 加权进度

进度由阶段门贡献计算。只有到 closed 的成果才计入阶段 100%。Check 可导致进度回退，这是质量系统正常工作。

### 成果证据

每个“完成”状态必须链接至少一项可复核证据：文件、结构化数据、测试记录、评审记录、读者测试、案例结果或裁决记录。没有证据的完成项视为声明，不进入进度。

### 预测与校准

执行效率按 WorkPacket 的执行周期、核验周期、返工次数、缺陷和人工裁决次数留痕。至少五个同 profile、同复杂度包后，才用历史 P50–P80 给出周期区间。成功概率必须有可校准历史，否则标为不可预测。

质量进展同时报告阶段门完成率、SLO、置信向量和风险加权不确定性负荷，不把它们压成单一健康分。
