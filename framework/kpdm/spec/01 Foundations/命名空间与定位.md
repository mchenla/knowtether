# KPDM 命名空间与定位

## 正式身份

| 字段 | 权威值 |
|---|---|
| 中文名称 | 知识产品开发元模型 |
| 英文名称 | Knowledge Product Development Meta-Model |
| 缩写 / namespace | KPDM |
| 定位语 | 由人主导、AI Agent 主动辅助的原创知识开发框架，支持框架、书籍、文章、报告及系列成果 |
| 最近接受基线 | 0.4.0 trial / conditional-pass |
| 当前正文 | 0.5.0-rc.2 candidate，待作者接受 |
| 出版表达 | 《知识产品工程：AI时代的人机协作创作元模型》（独立作品，另行同步） |

## 定位

KPDM 是开发知识产品的元模型，而不是某一主题的知识库、通用项目管理方法、个人资料收藏系统或自动写作工具。它规定所有实例共享的对象、关系、原则、协议、阶段门、质量控制和演进规则，并通过 Profile 适配框架或知识体系、书籍、文章、报告、系列成果及其配套工具。

人主导、Agent 主动辅助是 KPDM 的核心生产范式，但不是名称边界。框架同时支持不使用 Agent 的创作，模型应能在 AI 工具变化时继续成立。当前不以独立软件为交付前提；机器模型是可选支持，核心工作可用普通文档完成。

## 命名规则

- 项目与权威内核：`KPDM`；
- 协议：`KPDM-<DOMAIN>-<NN>`，例如 `KPDM-INIT-01`；
- 决策：`KPDM-D<NNN>`；
- PDCA：`KPDM-PDCA-<NN>`；
- 产品需求文档：`KPDM-PRODUCT-REQ-<NN>`（与协议 `KPDM-PRD-01` 区分）；
- 出版实例：`KPDM-PUB-*`；
- 机器实例：`kpdm.v<version>.json`；
- Schema：`kpdm.schema.v<version>.json`；
- JSON Schema `$id` 基址：`https://kpdm.local/schema/`。

## 兼容与迁移

`Meta-Framework` 与 `MF-*` 是 v0.1–v0.3 的旧命名空间。历史决策、PDCA、案例和机器快照保持原值，不得为了视觉统一回写。主动规范从 v0.4 起使用 KPDM。

| 旧标识 | 新标识 | 状态 |
|---|---|---|
| Meta-Framework | KPDM / 知识产品开发元模型 | deprecated alias |
| MF-INIT-01 | KPDM-INIT-01 | replaced-active |
| MF-HAI-01 | KPDM-HAI-01 | replaced-active |
| MF-PRD-01 | KPDM-PRD-01 | replaced-active |
| MF-PROD-01 | KPDM-PROD-01 | replaced-active |
| MF-WP-01 | KPDM-WP-01 | replaced-active |
| MF-RC-01 | KPDM-RC-01 | replaced-active |
| meta-framework.v0.1–v0.3 | kpdm.v0.4+ | historical snapshots |
| meta-framework.schema.v0.2–v0.3 | kpdm.schema.v0.4+ | historical schemas |

旧标识仍可引用，但不得用于新对象。兼容入口只负责重定向，不具有独立规范权威。
