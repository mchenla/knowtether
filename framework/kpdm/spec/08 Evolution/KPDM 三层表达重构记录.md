# KPDM 三层表达重构记录

## 决定

KPDM 采用三层表达：

1. Core-6：目的、知识内核、依据、可用化、表达、验证与演进；
2. Quality Constraints：真实性、人类可理解性、概念克制、权利安全、认知诚实与可追溯性；
3. Production Controls：ContextPack、WorkPacket、SLO、Gate、PDCA、人机协作、回归、版本与发布。

## 边界

- 同时兼容人类独立创作与人类—智能体协作；
- 当前覆盖以认知、判断、学习、行动或创造为目的的知识创作；
- 知识型叙事在范围内，纯文学与纯艺术暂不纳入；
- 不增加元对象，不改变现有 27 对象枚举，不立即扩展复杂 Schema；
- 27 个对象被重新解释为 Core-6 的实现词汇与跨层生产控制。

## 质量裁决

- 可用化定义为把知识内核转化为目标受众可完成的理解、判断、学习、行动或创造任务；
- 验证以这些任务的完成情况为主要依据之一；
- 人类可理解性在 Q0–Q2 是改进项，在 Q3/Q4 公开知识产品中是发布硬门；
- 新增概念克制与反迎合约束，禁止术语炫技、无依据评价和以赞美替代判断。

## 版本说明

本次属于 0.4.0 trial 的语义分层与澄清，不表示外部有效性已经提高。是否形成 0.5.0，待跨 Profile 实例验证与正式发布裁决。
