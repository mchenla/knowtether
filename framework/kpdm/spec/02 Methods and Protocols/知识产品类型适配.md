# 知识产品类型适配

## 共享内核

各类产品共用 Core-6、六项质量约束、问题、受众、概念、主张、证据、架构、校验、版本和反馈对象。差异只在深度、表达单元、控制强度和读者任务。

框架或知识体系、书籍、文章、报告、系列成果五种 Profile 地位平等。本轮优先验证文章与报告的轻量入口，并继续用框架或书籍检查复杂任务；这是验证顺序，不是重要性排序。

所有 Profile 都从 [上下文包与工作包协议](%E4%B8%8A%E4%B8%8B%E6%96%87%E5%8C%85%E4%B8%8E%E5%B7%A5%E4%BD%9C%E5%8C%85%E5%8D%8F%E8%AE%AE.md) 的工作单开始；命中 [KPDM 生产控制层](KPDM%20%E7%94%9F%E4%BA%A7%E6%8E%A7%E5%88%B6%E5%B1%82.md) 的触发条件时展开。轻量记录不得删除来源、权利、读者任务、未知项和人的决定。

本文件是 Profile 的唯一权威源；[KPDM 三层元模型](../01%20Foundations/KPDM%20%E4%B8%89%E5%B1%82%E5%85%83%E6%A8%A1%E5%9E%8B.md) 只保留指针。

## Profile A｜框架或知识体系

| 项 | 内容 |
|---|---|
| 目的 | 让使用者在不同场景中建模、诊断、设计、裁剪或决策 |
| 结构重心 | 领域范围、术语、对象模型、原则与方法、工具、权威矩阵、版本治理 |
| 控制裁剪 | 展开路径；权威矩阵与变更影响记录强制；多场景验证 |
| 默认质量目标 | Q4 Authority Candidate |
| 读者任务 | 用框架解释、诊断或指导一个使用者自己的场景，并说出适用范围 |
| 最小验证方向 | 能否在至少两个性质不同的场景中裁剪而不产生矛盾 |
| 重点风险 | 抽象完整但不可用；自定义概念过多；认证承诺早于验证 |

## Profile B｜书籍

| 项 | 内容 |
|---|---|
| 目的 | 让读者理解一个中心命题，并跨章节迁移所得认识 |
| 结构重心 | 中心命题、读者变化、全书论证架构、章节职责、每章主张—证据—案例链 |
| 控制裁剪 | 展开路径；权威矩阵强制；编辑、事实核查、引用、法律和版式检查 |
| 默认质量目标 | 公开出版至少 Q3；旗舰著作 Q4 候选 |
| 读者任务 | 复述中心命题与章节关系；把某章方法用到自己的问题上 |
| 最小验证方向 | 目标读者能否理解并跨章节迁移；定义在各章是否一致 |
| 重点风险 | 目录代替架构；重复论证；营销语言超过证据 |

## Profile C｜文章

| 项 | 内容 |
|---|---|
| 目的 | 让读者就一个问题形成更准确的判断、理解因果或采取行动 |
| 结构重心 | 一个清楚的问题；一个中心主张与必要的分论点；直接证据、反例或限制；明确读者和结尾的认知或行动变化 |
| 控制裁剪 | 轻量入口；发布前事实与引用核查；高风险事实或权利不明时展开 |
| 默认质量目标 | 对外发布 Q3；纯私人草稿可为 Q1 |
| 读者任务 | 复述主旨、适用范围和所得 |
| 最小验证方向 | 至少一位目标读者能复述主旨与适用范围 |
| 重点风险 | 把局部观点伪装成普遍规律；分论点多于证据 |

文章不需要完整知识体系。既有短文试验使用的「不超过 1000 字、不超过三个分论点」只约束该试验，不是所有文章的规则。

## Profile D｜报告

| 项 | 内容 |
|---|---|
| 目的 | 让接收者据此理解情况或作出相应决定 |
| 结构重心 | 问题、分析、判断、结论与建议之间的关系必须可追：每条建议能回到某个判断，每个判断能回到分析和依据 |
| 控制裁剪 | 轻量入口；含数据、强因果或高影响建议时逐项来源核对与领域复核；接收者之外流通时按公开发布处理 |
| 默认质量目标 | 内部用途 Q2；对外发布至少 Q3；涉及高风险判断时加严核验 |
| 读者任务 | 说出报告回答了什么问题、依据是什么、建议在什么条件下成立 |
| 最小验证方向 | 接收者能否据此作出预设的决定；建议与依据之间没有断链 |
| 重点风险 | 结论先于分析；建议超出证据；把估算写成观测事实 |

## Profile E｜系列成果

| 项 | 内容 |
|---|---|
| 目的 | 让读者在不同媒介中获得一致的内核，并完成分层任务 |
| 结构重心 | 共享术语、主张登记、内容依赖、去重规则、各单元的读者任务 |
| 控制裁剪 | 展开路径中的版本化 ContextPack 与变更影响记录强制；单元本身可按文章或报告轻量处理 |
| 默认质量目标 | 对外发布 Q3 |
| 读者任务 | 从任一单元进入，能找到内核与其他单元的关系 |
| 最小验证方向 | 一处改动能否正确传播到其他单元；内容是否重复或冲突 |
| 重点风险 | 各单元各自重定义；旧单元沿用已改动的主张 |

## 按读者任务组合的适配

教科书、课程、手册、工具书和工具包不设独立 Profile，按读者任务组合上述要求：

| 产品 | Core-6 的典型重心 | 可用化任务示例 | 加强的控制 |
|---|---|---|---|
| 教科书或课程 | 目的、知识内核、表达、验证 | 解释、区分、练习、迁移与解决问题 | 学习任务、概念递进和迁移测试 |
| 工具书、手册或工具包 | 可用化、表达、依据 | 检索、选择、执行和判断完成条件 | 检索、步骤、错误处理和完成判据 |
| 知识型叙事 | 目的、知识内核、依据、表达 | 形成更准确判断、理解因果或采取行动 | 事实与虚构标识；真实人物与事件的权利与隐私 |

| 出版工程 | 中 | 强 | 按渠道 | 按接收者 | 按渠道 |
