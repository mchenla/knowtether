# 轻量工作单

- 任务（一句话）：
- 成果类型：框架或知识体系 / 书籍 / 文章 / 报告 / 系列成果
- 版本 / 日期：
- 整合责任人：

| 项 | 要写什么 | 可以引用什么 | 内容 |
|---|---|---|---|
| 意图 | 为谁、解决什么、形成什么成果、内部或公开用途、Q 目标 | 项目章程、任务原话 | |
| 中心思想 | 当前主张、拟议贡献、尚未决定的问题；探索任务写研究问题与「主张未定」 | 主张—证据台账 | |
| 表达结构 | 作品任务写读者如何理解这件成果；研究任务写或引用暂定知识概览 | 稿件目录、大纲、知识概览 | |
| 依据与适用范围 | 来源及支持位置、推理、冲突、反例、未知；权利与敏感信息状态 | 来源与权利台账、数据引用记录 | |
| 委托范围 | 人与 Agent 各负责什么；输入版本；探索范围与预算或停止条件；何时返回人判断 | 人机协作记录 | |
| 验收条件 | 读者任务、必要核验、通过条件、核验责任 | QualitySLO | |
| 结果与修订 | 实际检查、失败项、修改、仍开放的问题 | 检查记录 | |
| 人的决定 | 接受或退回的内容版本、实质取舍、独立的发布决定 | 决策记录 | |

前六项在起草前写到够用；后两项随检查更新。研究交付只需与研究任务相适应的前六项，主张和结构可以暂定。填「不适用」时说明原因；缺失信息写「未知」，不补成事实。

## 展开检查

出现下列任一情况，按 [KPDM 生产控制层](../02%20Methods%20and%20Protocols/KPDM%20%E7%94%9F%E4%BA%A7%E6%8E%A7%E5%88%B6%E5%B1%82.md)「增加控制的触发条件」增加对应记录：

- [ ] 数据、强因果判断或高影响建议
- [ ] 权利不明或敏感材料
- [ ] 多章节、多成果或多人依赖
- [ ] 核心定义或方法变化
- [ ] 公开发布（至少 Q3，见 [发布前合规与完整性检查](../03%20Quality%20and%20Governance/%E5%8F%91%E5%B8%83%E5%89%8D%E5%90%88%E8%A7%84%E4%B8%8E%E5%AE%8C%E6%95%B4%E6%80%A7%E6%A3%80%E6%9F%A5.md)「轻量入口的最少检查」）
