# 实例化初始化协议

任何框架、知识体系、著作、出版物或文章在进入实质 Do 前，必须完成 KPDM-INIT-01。

## 初始化十二步

1. 创建独立项目目录和唯一 project_id；
2. 选择产品 Profile：知识体系、著作、文章或系列内容；
3. 定义问题、受众、使用情境和预期变化；
4. 选择质量目标 Q0–Q4；
5. 冻结范围、不做事项、时间和资源；
6. 声明中心命题、候选贡献和主要风险；
7. 建立概念、主张、来源、证据、数据、权利和决策台账；
8. 指定唯一权威来源和派生视图；
9. 定义人机角色、禁止委托事项和人工核验点；
10. 选择引用体例、版权辖区、许可策略、隐私与保密等级；
11. 建立阶段门、权重、首轮 PDCA 和失败条件；
12. 生成 README、索引、路线图、变更日志、ContextPack v1 和首个 WorkPacket。

## 初始化必备文件

| 文件 | 作用 |
|---|---|
| README | 项目定位与入口 |
| 项目章程 | 问题、受众、范围、质量目标 |
| 权威矩阵 | 唯一定义源与派生视图 |
| 主张—证据台账 | 论证与来源 |
| 来源与权利台账 | 许可、引用、隐私、保密 |
| 人机协作约定 | RACI、核验点、使用记录 |
| 进度看板 | Gate 权重与证据 |
| PDCA-01 | 首个可验证成果包 |
| ROADMAP | 阶段和下一轮 |
| CHANGELOG | 语义与成果变化 |
| ContextPack v1 | 冻结权威上下文和限制 |
| WorkPacket-01 | 冻结首项工作的输入、输出、SLO 和人工裁决点 |
| 不确定性登记 | 风险加权未知项及燃尽基线 |

## Init Gate

以下全部满足才允许进入 Do：

- Profile、Q 级和受众已选择；
- 外部发布项目至少定义 Q3 验收；
- 来源、版权、数据和 AI 使用协议已继承；
- 权威源、最终责任人和发布批准人明确；
- 首轮 PDCA 的产物、门槛和失败条件已冻结；
- ContextPack、首个 WorkPacket、QualitySLO 和测试已冻结；
- 没有未说明的机密数据或权利高风险输入。

## 快速文章例外

短文章可合并文件，但不能删除字段。至少保留：问题、受众、Q 级、中心主张、来源、权利状态、AI 核验点、发布 Check。
