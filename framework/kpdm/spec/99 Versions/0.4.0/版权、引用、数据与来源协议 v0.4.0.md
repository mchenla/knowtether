# 版权、引用、数据与来源协议

## 第一原则：来源、署名、许可是三件事

- 来源：读者能否追到材料；
- 署名：是否给予创作者和数据贡献者信用；
- 许可：是否有权复制、改编、翻译、展示、分发或商业使用。

三者不能互相替代。完整引用不等于获得许可；取得许可也不取消署名和许可证条件。

## 材料使用分类

| 类别 | 允许动作 | 必需记录 |
|---|---|---|
| 自有原创 | 按项目规则使用 | 作者、版本、首次形成时间 |
| 公共领域或 CC0 | 可复用，仍建议注明来源 | 权利判断依据、来源 |
| 开放许可 | 严格按具体许可证使用 | 版本、署名、链接、修改说明、SA/NC/ND 条件 |
| 明确书面许可 | 在授权范围内使用 | 权利人、范围、期限、地域、媒介、商业权利 |
| 法定例外候选 | 仅在完成适用法域审查后使用 | 目的、比例、转换性、市场影响和审查人 |
| 受限或机密 | 只在授权环境和用途内使用 | 数据所有者、保密级别、访问和发布限制 |
| 权利不明 | 不进入公开成品 | 待查事项和替代方案 |

## 使用方式必须声明

quote / paraphrase / summary / translation / adaptation / figure_reuse / table_reuse / code_reuse / data_reuse / derived_calculation。

“二次加工开发”不是权利类别。翻译、删节、改编、重绘或大量改写可能仍属于基于既有作品的使用；必须保留来源并确认权利基础。

## 文本引用

- 直接引语必须与原文一致，使用引号或块引，并给出页码、章节、段落或稳定定位；
- 转述必须真正重述，不得只换同义词；独特观点仍应归属原作者；
- 摘要不得替代许可去复现作品的核心表达或完整结构；
- 累积引用量也要检查，不能把许多短引文拼成对原作的实质替代；
- 无法核实原文的二手引语不得伪装成一手引用。

## 图、表、图片、截图和代码

- 原样复用通常需要明确许可或适用许可证；
- 重绘他人图表必须注明“根据某来源改绘”，并检查底层数据及表达的权利；
- 图片记录作者、作品名、来源、许可证、版本和修改；
- 截图同时检查软件界面、个人信息、商标和保密；
- 代码记录仓库、提交版本、许可证和修改；许可证不兼容时不得并入。

## 数据引用协议

凡外部数据支撑主张，数据必须像出版物一样进入参考或数据来源清单。最低字段：

| 字段 | 要求 |
|---|---|
| creator | 数据创建者或机构 |
| dataset_title | 数据集正式名称 |
| publisher_repository | 发布者或可信仓库 |
| version | 数据版本或发布日期 |
| persistent_id | DOI、稳定 ID 或稳定 URL |
| access_date | 实际访问日期 |
| license_rights | 许可证、使用条款和限制 |
| coverage | 地域、时间、总体和样本 |
| variables_units | 使用变量、口径和单位 |
| extraction | 查询、筛选和下载方式 |
| transformation | 清洗、合并、估算、通胀或汇率处理 |
| calculation | 公式、代码或作者计算 |
| uncertainty | 缺失、误差、偏差和不可比性 |

## 数字的三种标注

1. 原始引用数字：直接给数据来源；
2. 作者计算：写“作者根据 X 数据计算”，保留公式和输入版本；
3. 估算或模型输出：写明假设、方法、区间和敏感性，不得伪装为观测事实。

图表脚注至少包含 Source、Version/Date、Transformation。若使用多源数据，列出全部来源和合并逻辑。

## 数据可复现

Q3/Q4 产品的关键数字必须能复算。保存原始快照或持久标识、处理步骤、计算文件、生成日期和结果校验。来源后来更新时，不静默替换历史数字。

## 权利审查门

发布前按材料逐项得到以下状态之一：

- cleared-owned；
- cleared-public-domain；
- cleared-license；
- cleared-permission；
- cleared-exception-reviewed；
- restricted-internal-only；
- blocked-unknown-rights。

blocked 状态不得发布。

## 参考依据

- 美国版权法将改编权列为版权人的专有权，并区分既有材料和新增作者贡献：[17 U.S.C. §§101–106](https://www.copyright.gov/title17/92chap1.html)。
- 美国版权局明确指出，不能仅因对他人作品作了大量修改就主张其中既有作品的权利：[Fair Use FAQ](https://www.copyright.gov/help/faq/faq-fairuse.html)。
- CC 许可要求核对具体许可证版本、署名、许可链接和修改说明；ND、NC、SA 条件不可忽略：[Creative Commons FAQ](https://creativecommons.org/faq/index.html)。
- 数据引用应支持信用、证据、唯一标识、访问和持久性：[FORCE11 Data Citation Principles](https://force11.org/group/joint-declaration-of-data-citation-principles-final/)。
- DataCite 使用结构化元数据和持久标识支持数据识别、引用和检索：[DataCite Metadata Schema](https://schema.datacite.org/)。
