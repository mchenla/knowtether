## 范围和方法

依[生成前固定的方案](adaptive-eval-protocol.md)，比较两件事：短文在停用、0.4.1旧版和0.5.0新版中的资源开销；复杂写作在新版与停用中的内容表现。固定gpt-6.1-sol、medium，禁止联网。两次相反顺序重复、全程串行；每次新会话、新只读项目和相同[资料摘记](../examples/knowledge-work-sources.md)。三类复杂产品是完整研究综述、8页管理汇报内容、工具书章节，均无需提示标签。

资料来自真实公开研究，但仅限摘记明确提供的内容；两份材料未取得论文全文。这不是完整系统综述、实际组织试点或读者研究。公开记录任务、资料、输出散列、逐项判断和资源指标；长篇初稿及无推理内容的原始事件本地留存。

隔离的Codex HOME中不含私人KPDM Hook或Skill；每次通过原生安装器核对版本，从配置切换启停，再核对宿主清单和实际回调。单用CLI的enabled覆盖在此宿主上不能可靠改变发现结果，因此不把它作为隔离依据。安装准备不计入任务耗时。测量宿主为Windows、Codex 0.163.0-alpha.10.2。

最终答案以随机编号遮蔽条件标签，先按[预定标准](../examples/complex-work-cases.json)完成开发AI审阅并冻结，再揭示条件。编号不能防止从文字推测条件，审阅者也是开发者；不是独立人工、严格盲评或真实读者验证。不合并“质量总分”，不把标点、规范读取或篇幅增加当作内容质量收益。

## 复核入口

`scripts/adaptive_work_eval.py`负责实际调用，`scripts/summarize_adaptive_eval.py`核对完整18份记录、资料散列、启停清单、原文上下文和零项目修改，再生成遮蔽标签的审阅包。需要已安装并经正常审阅信任的隔离配置及原生CLI，会消耗模型用量；脚本不复制登录凭据、不授予Hook信任。公开[结果记录](../examples/adaptive-0.5.0-results.json)保留来源范围、输出身份、逐项理由与限制。

## 解释限制

每类产品只有两对，不能估计稳定效应、错误率或所有模型的表现。输入token含缓存和多轮累计；它不是实际账单。耗时包含宿主、工具与模型波动，不是纯Hook性能。停用组仍是有能力的基础模型，并收到明确任务和资料包；平局可能说明这类任务本身已足够明确，不能推成插件在所有环境都无效。

语言自然度及可用性由桌面审阅判断，没有真实目标读者。未测试统计水印清除、AI检测规避、所有Unicode排版语义或所有语法问题。本次软件发布不改变KPDM候选状态，也不证明完整学科已经成立。
